## Week 3

This week I completed onboarding Lab 3, where I learned how to build and verify a First-In, First-Out (FIFO) queue module in SystemVerilog. I gained hands-on experience structuring module hierarchy by composing larger digital designs from smaller functional modules. For the RTL design, I implemented a FIFO using a underlying memory array, read/write pointers, and occupancy tracking logic to handle status signals like full and empty.

A problem I came across was while building the verification environment. My first problem was a Verilator compile failure with 14 errors, all "can't find definition" errors for the reference queue (expected_queue) and my statistics counters (n_writes, n_reads, and so on). The randomized-test tasks used these names, but they weren't declared in a scope the tasks could see. I fixed this by declaring the queue and counters at module level, before the tasks that use them, so every task could access them.
