## Week 2

I read two pieces on how a processor runs instructions. In Patterson and Hennessy Chapter 4, I traced a single-cycle MIPS datapath for lw, sw, add, sub, AND, OR, slt, beq, and jump. The clock has to fit the slowest path, which wastes time, so pipelining overlaps instructions. Epstein's E20 manual is the 16-bit CPU I am building: $0 stays zero, memory has 8192 words, and the same code runs on single-cycle, multicycle, or pipelined hardware with forwarding and stalls.

## Week 3

I traced the S-type store path on the single-cycle datapath.

The S-type store path handles sb, sh, and sw. Opcode 0100011 selects it. A 12-bit immediate is assembled from instr[31:25] and instr[11:7], then sign-extended to 32 bits so a negative offset stays negative. ALUSrc selects this immediate instead of rs2, and the ALU adds it to rs1 to form the address. The rs2 value bypasses the ALU and is written to memory. MemWrite is 1 and RegWrite is 0, because a store does not write a register. funct3 selects an 8-, 16-, or 32-bit write. A separate adder computes PC + 4, since the ALU is already busy with the address.
