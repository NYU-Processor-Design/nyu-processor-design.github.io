## Week 2  9/21-9/28
Week 2 I attended the weekly meeting, went over the basics of Computer Architecture in the Patterson and Hennessy textbook.
Reviewed the basic structure of a processor and how the datapath and control unit work together. The datapath is how the data moves and get operated on; the control executes the instruction and controls the datapath. This chapter also covers sequential and combinational logic. Combinational logic depends on the current inputs, while sequential stores value across clock cycles. The main concept is about single cycle processor design, in which each instruction should finish within one cycle.
