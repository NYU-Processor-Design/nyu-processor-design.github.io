## Week 1
This week I completed lab2 and read the Patterson and Hennessy textbook. I learned that the register file can read and write to the same register in one clock cycle. This works because the old value is read first, and the new value is only saved at the clock edge. So, reading and writing at the same time will not mess up the data.

## Week 2

This week, I worked on the single-cycle RISC-V processor design. My main contribution was the "JALR" instruction path. JALR does two main things, which are `PC = rs1 + immI` and `rd = old PC + 4.`

The 12-bit immediate is sign-extended to 32 bits before going into the ALU. The ALU adds `rs1` and the immediate to get the jump address. The lowest bit of the result is then forced to `0`. I also added the `PC + 4` writeback path so the return address can be stored in `rd`.
