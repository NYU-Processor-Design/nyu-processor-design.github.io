## Week 1
This week I completed lab2 and read the Patterson and Hennessy textbook. I learned that the register file can read and write to the same register in one clock cycle. This works because the old value is read first, and the new value is only saved at the clock edge. So, reading and writing at the same time will not mess up the data.
