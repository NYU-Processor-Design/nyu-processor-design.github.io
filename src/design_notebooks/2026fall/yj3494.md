## Week 3

This week, I worked on the Group B processor schema design.

I reviewed the RV32I instruction formats and learned more about how the PC, register file, ALU, immediate values, multiplexers, and control unit work together in a single-cycle processor.

My main contribution was adding support for the U-type instructions LUI and AUIPC.
For both instructions, I added a U-type immediate generator:
immU = {instr[31:12], 12'b0}
For LUI, the generated immediate is written directly back to the destination register rd.
For AUIPC, the generated immediate is added to the current PC using a 32-bit adder, and the result is written back to rd.
I also added the opcode connection, RegWrite control, writeback selection, rd address connection, and bus-width labels.
This helped me better understand how instruction fields are decoded and how different instructions use different datapath paths while sharing the same processor components.
